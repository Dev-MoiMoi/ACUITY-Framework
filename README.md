"# ACUITY Framework (`acuity-framework`)



\[!\[Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)

\[!\[License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)



\*\*ACUITY\*\* (\*\*A\*\*utomated \*\*C\*\*ommunity \*\*U\*\*nstructured \*\*I\*\*nformation to \*\*T\*\*argeted visibilit\*\*Y\*\*) is an open-source, pip-installable Python framework designed to bridge the digital visibility gap for informal micro-enterprises. It automates the end-to-end pipeline: extracting business data from unstructured social media posts, validating legitimacy against official government registries, and delivering ranked local business recommendations."
